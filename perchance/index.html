  1. Copy the stylesheet from the Stylesheet tab (or download the .css file).
  2. In Jellyfin, open Dashboard → Branding and paste it into the Custom CSS field, then click Save.
  3. Reload the web client (hard refresh) to see the theme. Any client that uses Jellyfin Web gets it — other clients ignore custom CSS.

Per-user instead? Put the same CSS in Settings → Display → Custom CSS — it applies to just your account.

Version coverage. The generated sheet has three parts: a :root block that drives the new Jellyfin 10.11+ palette variables, a classic-selector block that styles 10.8 through 10.10 (and still applies on 10.11), and optional extras (wallpaper, scrollbars, webfont). Unknown rules are simply ignored by older or newer builds.

External assets. A wallpaper URL or a webfont is fetched by each client device, not by your server — so it needs internet access on the devices you use, and it will not work fully offline. Choosing System or Jellyfin-bundled fonts keeps a theme fully self-contained.

Fonts & licences. The stylesheet header credits every family it pulls in, with its licence (OFL, Apache-2.0 or the Fontshare/ITF Free Font Licence). Free-foundry faces (Velvetyne, The League of Moveable Type) are served as @font-face files from jsDelivr, which is fine for personal and commercial use with attribution kept in the header. Google-family imports can also be pointed at Bunny Fonts from the Typography panel if a device can't reach Google.

Themes vs plugins. Many community themes are distributed as a hosted .css you pull in with @import url(...). Pasting your sheet directly avoids that network dependency entirely.
